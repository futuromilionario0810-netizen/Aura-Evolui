# AURA — Evolução diária

PWA instalável para celular. Envie todos os arquivos e a pasta `icons` para a raiz de um repositório GitHub. Importe no Vercel como projeto **Other**, sem build command e com diretório de saída vazio.

## Regras
- Crie atributos com nome, regra de +1 e regra de −1.
- Atributo criado só aparece na data de criação e nos dias seguintes.
- Edições valem da data da edição em diante; versões e pontuações anteriores permanecem preservadas.
- Histórico, total acumulado, metas (10, 25, 50, 100, 200 e 365), navegação entre dias e exportação de backup JSON.

## Armazenamento
Os dados ficam no navegador/dispositivo e não sincronizam automaticamente entre aparelhos. Exporte backups periodicamente.
